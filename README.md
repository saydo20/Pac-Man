# Pac-Man

## About

This project is a full recreation of the classic arcade game **Pac-Man**, built in
Python. It includes a playable maze, a player controlled by the keyboard, ghosts with
their own AI, a scoring system, a persistent highscore list, and a menu-driven UI. The
maze itself isn't handwritten — it's generated by an external package we integrate into
our game.

## Starting tasks

1. **Learn Pygame** — Get comfortable with the basics: opening a window, the game loop,
   drawing shapes/images, handling keyboard input, and moving something on screen. You
   don't need to be an expert, just enough to build and iterate comfortably.
2. **Work on the backend — logical maze** — Build the data structure that represents the
   maze internally (grid of walls/corridors/paths), independent of how it's drawn. This
   is what the player, ghosts, and collision logic will all rely on, so it needs to be
   solid before we build gameplay on top of it.

## What is Pygame

Pygame is a Python library for building 2D games. It gives you the pieces you'd
otherwise have to build yourself: a window to draw in, a loop to keep the game running,
tools to draw shapes and images, keyboard/mouse input handling, collision detection
helpers, and basic sound support. It's not a game engine with a fancy editor — it's a
toolkit you code against directly, which is why it fits a project like this where we
want full control over the game loop and logic.
